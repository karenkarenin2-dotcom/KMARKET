# KMARKET

**Трекер цен World of Warcraft. Отвечает на один вопрос: брать сейчас, ждать или продавать.**

KMARKET by KareninTeam · регион EU (+ US как опережающий индикатор)

---

## Что это

Blizzard отдаёт через свой API только **текущие** цены — никакой истории.
KMARKET копит историю сам, круглосуточно, по жетону и по товарам аукциона,
которые ты выбрал (поиск по названию прямо в окне), и превращает её в ответ:

- **Вердикт** — брать / ждать / не сейчас, с объяснением, почему именно так.
- **Перцентиль цены** — «сейчас 12-й перцентиль за 90 дней» честнее, чем «дёшево».
- **Недельный ритм** — в какой день и час по времени EU-серверов цена
  исторически ниже и выше всего.
- **Цикл контента** — как цена вела себя вокруг патчей и сезонов: перед ними
  дорого, после — дёшево. Самый сильный сигнал, какой нашёлся в данных.
- **Уведомления в Telegram** — шлёт облако, компьютер для этого не нужен.
  Бот односторонний: только присылает, команд не понимает.

## Как устроено

Три независимых слоя:

1. **Сборщики** — GitHub Actions, ноль зависимостей и ноль затрат. Жетон — раз
   в 20 минут, аукцион — раз в час (чаще Blizzard не обновляет). Пишут историю
   прямо в этот репозиторий. Работают, даже когда компьютер выключен.
2. **Аналитика** — чистые функции над накопленной историей.
3. **Приложение** — окно на WebView2, запускается из папки `launch/`.
   Ничего в фоне не держит: закрыл — и на компьютере не осталось ни одного
   процесса. Уведомления к нему не привязаны, их шлёт облако.

История лежит в `data/history/` (жетон) и `data/auction/` (товары) — обычные
CSV, которые можно открыть чем угодно.

```
kmarket/   ядро: сбор, аналитика, приложение
data/      история цен
launch/    запуск: KMARKET.bat
docs/      документация — начать с docs/ЗАПУСК.md
```

## Запуск

Подробно — в [docs/ЗАПУСК.md](docs/ЗАПУСК.md). Коротко:

```bash
# 1. Секреты (ключи — на https://develop.battle.net/access/clients)
cp .env.example .env   # и заполнить

# 2. Зависимости (нужны только приложению и аналитике, не сборщику)
pip install -r requirements.txt
```

Дальше — двойной клик по `launch/KMARKET.bat`. Из терминала то же самое:
`python -m kmarket`.

## Правила игры

KMARKET читает официальный Blizzard Game Data API, который Blizzard сама
предоставляет разработчикам. Игрового клиента проект не касается и не
автоматизирует — никаких аддонов, макросов и вмешательства в игру.
