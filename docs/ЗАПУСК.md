# Как запускать KMARKET

Всё, что нужно, лежит в папке **`launch/`**. Больше ничего устанавливать не надо,
никаких ярлыков на рабочем столе проект не создаёт.

---

## Дашборд (сайт с аналитикой)

Двойной клик по **`launch/KMARKET.bat`**.

Откроется чёрное окно консоли, через пару секунд сам откроется браузер на
`http://127.0.0.1:8765`. Первый расчёт занимает несколько секунд — считаются
события и бэктест по пяти годам истории.

В окне консоли видно, что происходит:

```
[KMARKET] История актуальна: Already up to date.
[KMARKET] Дашборд: http://127.0.0.1:8765/
[KMARKET] Остановить: Ctrl+C или просто закрой это окно.
```

**Выключить:** закрыть окно консоли (или Ctrl+C в нём). Закрытие вкладки браузера
сервер не останавливает — вкладка только зритель.

## Бот в Telegram (цена с телефона)

Двойной клик по **`launch/KMARKET_BOT.bat`**.

При старте бот пишет в консоль свой ник и **присылает в чат сообщение
«Бот KMARKET запущен»** — если оно пришло, связь работает. Дальше можно
отправлять команды:

| Команда | Что показывает |
|---|---|
| `/price` | цену EU и US живьём у Blizzard + перцентиль |
| `/verdict` | брать сейчас или ждать, с объяснением |
| `/season` | когда на неделе дешевле всего |
| `/events` | ближайшие патчи и их влияние на цену |

**Важно понимать разницу между ботом и алертами:**

- **Алерты приходят сами** и работают всегда, даже когда компьютер выключен —
  их шлёт GitHub Actions из облака при смене состояния рынка.
- **Команды бота работают, только пока открыто окно `KMARKET_BOT.bat`.** Бот
  сам опрашивает Telegram, поэтому без запущенного процесса отвечать некому.
  Команды, отправленные пока бот спал, он ответит при следующем запуске (если
  им меньше суток).

**Не запускай две копии бота** — Telegram разрешает опрашивать бота только
одному процессу, второй получит ошибку и закроется с понятным сообщением.

## Если что-то не работает

**Окно мигнуло и закрылось.** Так быть не должно: в обоих батниках стоит `pause`,
окно обязано остаться и показать причину. Если всё же закрылось мгновенно —
скорее всего не найден `python`.

**Жалуется на модули (`ModuleNotFoundError`).** Поставить зависимости, из корня
проекта:

```bash
pip install -r requirements.txt
```

**«История не обновлена — работаю на локальной копии».** Не поломка: git не смог
подтянуть данные из облака (нет сети, или есть локальные изменения). Дашборд
работает на том, что есть на диске, а цену в заголовке всё равно спрашивает
у Blizzard напрямую. В консоли рядом печатается причина.

**Порт занят.** Значит дашборд уже запущен в другом окне — новый сервер не
поднимается, просто откроется браузер на уже работающем.

**Бот не отвечает на команды.** Проверить, что окно `KMARKET_BOT.bat` открыто и
в нём написано «на связи». Если в консоли `409` — где-то запущена вторая копия.

## Что где лежит

```
kmarket/    ядро: сбор данных, аналитика, дашборд, бот
data/       история цен (CSV, читаются глазами)
launch/     запуск — эти два батника
docs/       документация (этот файл здесь)
CLAUDE.md   рабочие заметки для Claude: решения, находки, ловушки
```
