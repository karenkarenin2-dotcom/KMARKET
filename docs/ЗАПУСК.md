# Как запускать KMARKET

Всё, что нужно, лежит в папке **`launch/`**. Больше ничего устанавливать не надо,
никаких ярлыков на рабочем столе проект не создаёт.

---

## Приложение

Двойной клик по **`launch/KMARKET.bat`** — откроется окно программы.

Раньше это был сайт в браузере; с 6 августа 2026 года это обычное окно.
Ни порта, ни сервера, ни вкладки среди двадцати других больше нет.

Внутри две вкладки:

- **Жетон** — брать сейчас или ждать, с объяснением каждого довода, график
  цены и перцентили по пяти окнам.
- **Аукцион** — товары под слежкой и «недооценённые прямо сейчас»: где
  можно выкупить дешёвый хвост и перевыставить по рынку.

Первый расчёт занимает несколько секунд: считаются события и бэктест по
пяти годам истории. Окно в это время уже открыто и живое.

**Выключить:** крестик в правом верхнем углу. Окно безрамочное, поэтому
свернуть/развернуть/закрыть — наши кнопки; развернуть можно ещё и двойным
щелчком по шапке.

### Что показывает вкладка «Аукцион»

| Колонка | Что значит |
|---|---|
| **Цена сейчас** | цена самого дешёвого лота — столько стоит купить штуку |
| **Цена после** | куда вернётся прилавок, когда дешёвые лоты разберут |
| **Скупить всё** | сколько золота нужно на весь хвост ниже «цены после» |
| **Навар** | сколько останется чистыми после комиссии аукциона (5%) |
| **Совет** | «брать» — есть арбитраж; «копим» — по товару ещё нет истории |

**«Копим» — это не поломка.** Внешнего архива цен на товары не существует
(жетону когда-то залили историю с 2020 года, здесь заливать неоткуда), и
уровни цен станут осмысленными через пару недель накопления. А вот
колонка «Навар» работает с первого дня: она считает разрыв в прилавке,
а не историю.

**Осторожно с «Наваром».** Цифра честная арифметически: столько даст
выкуп хвоста, если продать по «цене после». Но сама по себе она не знает,
насколько быстро товар уходит.

Это и меряет строка «разойдётся за N часов» — она появляется, когда
сборщик успел сравнить достаточно снимков. До тех пор вместо неё стоит
«движение» или ничего, и тогда к цифре навара надо относиться как к
арифметике, а не к обещанию. Метка **«старьё»** рядом с названием —
предупреждение того же рода: большой разрыв у товара прошлых дополнений
обычно оттого, что его рынок никто не смотрит.

## Уведомления в Telegram

**Держать для них ничего не нужно.** Это единственное, что важно понять.

Уведомления шлёт GitHub Actions из облака — раз в час проверяет рынок и,
если что-то изменилось, пишет в личный чат с ботом **@kmarketwowbot**.
Компьютер при этом может быть выключен: он в этой цепочке не участвует
вообще.

О чём приходит:

| Повод | Когда |
|---|---|
| Окно покупки жетона открылось или закрылось | при смене вердикта |
| Глубокое дно — нижние 10% за 90 дней | при входе в зону |
| Скоро игровое событие | один раз, за 21 день |
| Слив на аукционе: дешёвый хвост с настоящей выгодой | при появлении |

**Бот односторонний, и это сделано намеренно.** Отвечать на команды он не
умеет — раньше умел, но для этого требовался постоянно запущенный процесс
на ПК, а держать что-то в фоне не хочется. Спрашивать бота не нужно: всё,
что он мог рассказать, есть в приложении, а важное он присылает сам.

**Спама не будет.** Дедуп идёт по СОСТОЯНИЮ (`data/alert_state.json`), а
не по расписанию: сообщение уходит, только когда что-то реально
изменилось. Проверка хоть каждый час на количество сообщений не влияет.

Порог для аукционных находок намеренно высокий — 10 тысяч золота. В
приложении показываются и находки от 500 з, но будить человека ради них
нельзя: разбуженный по пустякам отключит уведомления и пропустит важное.

## Если что-то не работает

**Окно мигнуло и закрылось.** Так быть не должно: в батнике стоит `pause`,
консоль обязана остаться и показать причину. Если всё же закрылась мгновенно —
скорее всего не найден `python`.

**Жалуется на модули (`ModuleNotFoundError`).** Поставить зависимости, из корня
проекта:

```bash
pip install -r requirements.txt
```

**«История не обновлена — работаю на локальной копии».** Не поломка: git не смог
подтянуть данные из облака (нет сети, или есть локальные изменения). Программа
работает на том, что есть на диске, а цену всё равно спрашивает у Blizzard
напрямую. В консоли рядом печатается причина.

**Окно не открывается совсем.** Нужен WebView2 Runtime. В Windows 11 он
предустановлен; если вдруг нет — поставить командой:

```bash
winget install Microsoft.EdgeWebView2Runtime
```

**Вкладка «Аукцион» пустая.** Значит ещё не собран список слежки. Собрать
(это несколько минут — заполняется справочник предметов):

```bash
python -m kmarket.watchlist
```

**Бот не отвечает на команды.** Так и задумано: он односторонний и умеет
только присылать. Спрашивать нечего — открой приложение.

**Уведомления перестали приходить.** Компьютер тут ни при чём. Смотреть надо
на вкладку Actions в GitHub: если задача `alert` краснеет, причина там. Ещё
GitHub отключает расписание в репозиториях, где 60 дней не было активности, —
но сборщик коммитит сам, так что активность есть всегда.

## Что где лежит

```
kmarket/    ядро: сбор данных, аналитика, окно приложения
data/       история цен и аукциона (CSV, читаются глазами)
launch/     запуск — KMARKET.bat
docs/       документация (этот файл здесь)
CLAUDE.md   рабочие заметки для Claude: решения, находки, ловушки
```

## Обслуживание раз в месяц

Список отслеживаемых товаров подбирается по ликвидности и после крупного
патча устаревает — новые реагенты надо подхватить. Пересобрать:

```bash
python -m kmarket.watchlist
```

Занимает несколько минут (заполняется справочник предметов) и печатает,
что попало в список. Результат — `data/watchlist.json` и `data/items.json`,
их надо закоммитить. То же самое умеет кнопка «Run workflow» у `auction`
на вкладке Actions в GitHub.

## Что происходит вокруг патча 12.1

С 7 августа сборщик пишет не только 400 отслеживаемых товаров каждый час,
но и **весь аукцион целиком** — все 12 тысяч предметов, четыре раза в
сутки, в `data/auction_wide/`.

Зачем: список слежки подобран ДО патча, и новых реагентов Coiled Isle в
нём нет — они ещё не существуют. Записать рынок целиком через запуск
сезона можно только пока это происходит; у Blizzard истории нет, потом
взять неоткуда. Стоит это 2.3 МБ в сутки.

**Выключится само 6 сентября** — дата зашита в код (`WIDE_UNTIL`), чтобы
временная мера не осталась навсегда. Делать для этого ничего не нужно.
